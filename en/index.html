Graecum VN · Ancient Greek

A completely free self-study hub for Ancient Greek – from zero to reading Plato, Xenophon, the Greek Bible (Koine) and intermediate–advanced texts. All content CC BY-SA 4.0, no ads, works offline.

English edition. Original (Tiếng Việt): Graecum VN portal. Lessons 1–5 are already published in Vietnamese; the English translations follow one by one.

How to work with each lesson

  1. Read on the web, or download the single HTML file of the lesson – study offline in any browser, no internet dependency.
  2. Want a Word copy: open the HTML file with MS Word → Save As .docx.
  3. To print: Ctrl+P → Save as PDF – exercise answers appear automatically when printing.
  4. Level I vocabulary always carries a Latinized transliteration so you can read aloud from day one (e.g. ὁ ἄνθρωπος → ho ánthrōpos).
